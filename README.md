# Exercícios Java — Alura

Repositório contendo exercícios e práticas realizadas durante formação de carreira BackEnd com Java da **plataforma Alura**, com foco no aprendizado da linguagem **Java** e conceitos fundamentais de programação.

---

## Cursos e tópicos estudados

### Fundamentos de Java

- Criando a primeira aplicação em Java
- Variáveis e tipos de dados
- Estruturas condicionais (`if` e `else`)
- Laços de repetição (`for` e `while`)
- Manipulação de data e hora

### Programação Orientada a Objetos

- Aplicando conceitos de orientação a objetos
- Criação de classes e objetos
- Encapsulamento

### Estruturas de dados

- Listas e coleções
- Streams

### Tratamento de erros

- Criação de exceções
- Lançamento de exceções
- Controle de exceções (`try`, `catch`, `finally`)
